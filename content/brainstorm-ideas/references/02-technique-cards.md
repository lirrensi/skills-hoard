# Technique Cards

Use these cards to generate range without losing direction.

## Default Sequence When Stuck

If you do not know what to run, do this:

1. generate 10 practical or obvious ideas
2. run one inversion pass
3. run one analogy pass
4. run one extreme-constraint pass
5. combine the strongest fragments into 5 hybrids
6. cluster and pick 3 directions to develop

## Coverage Rule

Across the full set, try to vary at least three of these:

- mechanism
- audience or stakeholder
- time horizon
- effort level
- cost profile
- risk level
- central assumption being challenged

## Technique Cards

### Baseline Sweep

Use when you need momentum or a baseline set fast.

Prompt moves:

- `List the obvious or standard ways to approach this.`
- `What would a competent team do first?`
- `What are the safe, boring, proven options?`

Why it matters: you need the baseline before you can tell whether later ideas are genuinely different.

### Inversion And Worst Idea

Use when the session feels too polite, too linear, or too attached to the current frame.

Prompt moves:

- `How would we make this fail on purpose?`
- `What is the worst possible solution?`
- `What is the opposite of the standard advice here?`

Then flip the output into useful moves.

### Extreme Constraints

Use when ideas are too incremental.

Prompt moves:

- `What if we had to ship in 24 hours?`
- `What if budget were zero?`
- `What if we had 10x the budget or reach?`
- `What if this had to work with no new tooling or no meetings?`

Extreme constraints expose hidden assumptions and force different mechanisms.

### Perspective Shift

Use when you need range across stakeholder needs or mental models.

Prompt moves:

- `How would a new user see this?`
- `How would an expert, operator, founder, regulator, or competitor approach it?`
- `What would matter to the most skeptical stakeholder?`

### Analogy Transfer

Use when local solutions are exhausted.

Prompt moves:

- `Who solves a similar problem in another field?`
- `What can we borrow from games, logistics, publishing, medicine, retail, or nature?`
- `What pattern transfers cleanly and what must change?`

### SCAMPER

Use when you have an existing concept, product, or workflow to mutate.

Prompt moves:

- `Substitute`: what can be replaced?
- `Combine`: what can be merged?
- `Adapt`: what can be borrowed?
- `Modify`: what can be enlarged, reduced, or reshaped?
- `Put to other use`: where else could this work?
- `Eliminate`: what can be removed entirely?
- `Reverse`: what if the sequence or relationship flips?

### Morphological Grid

Use when the space has several dimensions and you need systematic coverage.

How to run it:

1. choose 3-6 key dimensions
2. list 3-5 possible values for each
3. deliberately sample combinations
4. keep the combinations that create distinct concept directions

Good for architecture, workflows, delivery models, business models, and policy design.

### TRIZ-Light Contradiction Split

Use when improving one thing seems to worsen another.

Prompt moves:

- `What are we trying to improve?`
- `What gets worse when we do that?`
- `Can we separate these in time, place, condition, or interface?`
- `What would the ideal outcome look like if the trade-off vanished?`

Good for technical and systems problems.

### First-Principles Reframe

Use when convention is trapping the search space.

Prompt moves:

- `What problem are we actually solving?`
- `Which constraints are physical, economic, or legal, and which are inherited habit?`
- `If we started from scratch, what would we build?`

### Time Shift

Use when present assumptions feel too strong.

Prompt moves:

- `How would we solve this in 1995?`
- `How would we solve it in five years if the tech and market changed?`
- `What is the timeless version of the idea versus the trend-driven version?`

### Combination And Mutation

Use after you have enough raw material.

Prompt moves:

- `Combine idea 3 with idea 11.`
- `What is the lighter or faster variant of this?`
- `What is the premium, automated, or self-serve version?`
- `What if this cluster became a workflow, not a feature?`

### AI Co-Ideator

Use when you want rapid stimulus, clustering, or critique.

Good AI jobs:

- generating orthogonal prompt passes
- forcing analogies and opposites
- clustering and deduplicating raw ideas
- surfacing failure modes and hidden assumptions

Bad AI jobs:

- declaring the winning idea too early
- pretending repetition equals coverage
- replacing human judgment on feasibility or taste

### Incubation Reset

Use when the session stalls or gets repetitive.

Trigger signs:

- three or more ideas in a row are minor variations
- the same cluster keeps absorbing everything
- people start evaluating instead of generating

Reset moves:

1. pause for a short break
2. come back with a different technique
3. change the prompt angle, not just the wording

## Anti-Patterns

- running the same technique repeatedly after returns diminish
- confusing lots of words with lots of mechanisms
- using random stimuli without reconnecting them to the brief
- generating only wild ideas or only safe ideas
- staying in divergence after the space is already rich enough
