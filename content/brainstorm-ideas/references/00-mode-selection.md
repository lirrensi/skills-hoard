# Mode Selection

Pick the lightest ideation mode that expands the space without creating noise.

## Default Rule

Start with `hybrid-default` unless there is a strong reason not to.

That means:

1. generate individually or in parallel first
2. share and cluster the ideas
3. converge with a structured ranking or selection pass

This is the default because free-flow verbal brainstorming often feels productive while still losing output to blocking, status effects, and premature judgment. Use live group discussion mainly after a base set exists or when buy-in matters as much as idea volume.

## Triage Questions

Ask or infer these first:

1. Do we need raw breadth, a shortlist, or consensus?
2. Is this solo work, a team session, or an expert panel?
3. Will hierarchy, politics, or anxiety suppress participation?
4. Is the design space fuzzy, multi-dimensional, or contradiction-heavy?
5. Are we stuck because of fixation, repetition, or lack of structure?
6. Do we need ideas now, or ranked choices now?

## Mode Map

| Mode | Use When | Core Output | Watch Out For |
|---|---|---|---|
| `quick-spread` | the user is blank, blocked, or needs momentum fast | 10-20 raw directions | shallow variants if you do not switch methods soon |
| `hybrid-default` | most ideation work | broad set -> clusters -> candidates | skipping the cluster step |
| `brainwriting` | a group needs balanced participation with low blocking | parallel idea pool | weak prompts produce generic output |
| `ngt` | you need a prioritized shortlist now | ranked options | false precision if the framing is weak |
| `delphi-lite` | distributed experts need structured convergence | round-based consensus or narrowed list | slow cycles and panel drift |
| `morphology` | the space has multiple dimensions and you fear missing combinations | explicit design space map | combinatorial explosion |
| `triz-light` | the problem is a technical contradiction | contradiction-framed solution directions | forcing TRIZ on fuzzy human problems |
| `ai-co-ideation` | you want fast reframes, opposites, clustering, or critique | diversified prompt-driven idea set | repetition, genericness, and over-trust |
| `incubation-reset` | the session has stalled or become repetitive | refreshed second wave | treating a break as a substitute for switching method |

## Minimum Bundles

- Thin brief, low stakes -> `quick-spread` -> cluster -> top 3 directions
- Most product, strategy, and design work -> `hybrid-default`
- Team session with loud voices or uneven status -> `brainwriting` -> `ngt`
- Multi-parameter design problem -> `morphology` -> light scoring
- Technical contradiction -> `triz-light` -> prototype candidates
- Expert consensus -> `delphi-lite`
- AI-assisted exploration -> `ai-co-ideation` plus human clustering and selection

## Escalation Rules

Escalate from a lighter mode when:

- ideas are repeating in the same mechanism
- one stakeholder perspective is dominating
- the space feels large but under-mapped
- the user needs a defensible shortlist, not just more options
- there are real contradictions that generic prompts keep glossing over

## De-Escalation Rules

Move to a lighter mode when:

- the user only needs a few practical options
- the main blocker is clarity, not method sophistication
- the problem does not justify heavy structure or long ranking rounds

## Anti-Patterns

- defaulting to live verbal brainstorming as the main generator
- using a heavy method before the brief is clear
- treating consensus methods as creativity methods
- treating AI output as proof of diversity
- generating more ideas when the real need is clustering or choosing
