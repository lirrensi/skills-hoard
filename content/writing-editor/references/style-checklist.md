# Part 2 - Style and Readability Pass

Use this file as an operating procedure, not just a reminder list. Diagnose how the writing lands for the intended reader.

This pass checks clarity, tone, flow, rhythm, audience fit, and consistency. It does not re-run the full structure pass unless a structural blocker is impossible to ignore.

## Decision tree

### 1. Check reader orientation
- If the reader lacks a clear yardstick for what this piece is, why it matters, and how to read it, flag orientation trouble.
- If headings or topic sentences exist but do not actually orient the reader, flag weak signposting.

### 2. Check sentence clarity
- If a sentence requires rereading, ask why: length, syntax, density, pronoun ambiguity, jargon, or loose reference.
- If the meaning is still unstable after simplification, flag genuine ambiguity.
- If a sentence tries to do too many jobs at once, flag overload.

### 3. Check acoustic flow and attention
- If a passage works on the screen but stumbles when read aloud, flag acoustic drag.
- If your attention slips while reading silently or aloud, treat that as evidence and identify the cause: repetition, decorative language, density, weak progression, or monotony.
- If a sentence sounds more impressive than clear, flag flowery drag.

### 4. Check tone and register
- If the piece suddenly shifts from conversational to academic, breezy to solemn, confident to defensive, flag tone drift.
- If the prose sounds condescending, performatively clever, falsely modest, or oddly aggressive, flag relational mismatch.
- If technical language appears, test whether it serves precision or only prestige.

### 5. Check paragraph flow
- If two paragraphs sit next to each other without a visible bridge, flag transition weakness.
- If a paragraph contains multiple unrelated moves, flag paragraph overload.
- If the paragraph opens one move and ends on another, flag unstable focus.

### 6. Check rhythm and density
- If the piece feels tiring, ask whether the problem is information density rather than sheer length.
- If every sentence lands with the same weight or cadence, flag rhythm monotony.
- If compressed material is hard to absorb, suggest expansion, spacing, or sequence changes rather than only cutting.

### 7. Check significance and reader pushback
- If an important claim invites the response "So what?" and the text does not answer it, flag an uncashed claim.
- If a likely reader response is "Why should I care?" flag missing stakes, consequence, or implication.
- If a likely reader response is "Says who?" or "Why should I believe this?" flag weak support, vague evidence, or overstatement.

### 8. Check audience fit
- If the piece assumes knowledge the target reader likely does not have, flag under-explained context.
- If the piece explains obvious things at length for its likely audience, flag over-explanation.
- If the piece sounds written for a different audience than the one implied, flag audience mismatch.

### 9. Check consistency and trust
- If key terms, pronouns, labels, capitalization, list structure, or formatting logic drift, flag consistency trouble.
- If mechanical inconsistency makes the prose feel amateur or unstable, flag trust leakage.

## Core checklist

### Clarity
- [ ] Are there sentences that require rereading to understand?
- [ ] Are pronouns, referents, and key terms stable and clear?
- [ ] Is jargon necessary, defined, and suited to the audience?
- [ ] Are there places where the meaning is genuinely ambiguous?

### Acoustic flow
- [ ] Does the prose still work when read aloud?
- [ ] Are there places where the sound, cadence, or phrasing creates drag?
- [ ] Does attention hold, or does the prose induce avoidable drift?

### Tone and register
- [ ] Does the piece keep one intelligible voice?
- [ ] Are there unexpected register shifts?
- [ ] Does the tone fit the piece's purpose and relationship to the reader?

### Flow and rhythm
- [ ] Do paragraphs connect clearly to each other?
- [ ] Does each paragraph do one main job?
- [ ] Is sentence rhythm varied enough to keep the prose alive?
- [ ] Is pacing appropriate to the density of the material?

### Focus and emphasis
- [ ] Are important points given enough space?
- [ ] Are minor points taking up too much room?
- [ ] Are any lines flashy in a way that steals attention from the point?
- [ ] Do important claims answer "So what?"
- [ ] Does the draft answer obvious reader pushback soon enough?

### Audience fit
- [ ] Is the level of assumed knowledge appropriate for the intended reader?
- [ ] Is anything over-explained?
- [ ] Is anything under-explained?

### Consistency
- [ ] Are terms, labels, and references used consistently?
- [ ] Do headings, lists, and formatting choices help orientation?
- [ ] Are mechanical inconsistencies hurting trust or readability?

## Severity guide

- `reader stumble` - the reader can recover, but the prose makes them work too hard
- `style drag` - the prose is functional but weaker, flatter, or less precise than it should be
- `optional polish` - a worthwhile refinement, but not a meaningful blocker

## Output rules

- Prioritize notes that improve comprehension, trust, and audience fit before cosmetic polish.
- Point to the exact location that caused the problem.
- Name the cause when possible: density, syntax, ambiguity, abstraction, jargon, rhythm, transition, tone drift, acoustic drag, uncashed claim, or weak support.
- Give revision direction, not just complaint.
- You may give short example rewrites to illustrate how to shorten, clarify, merge, split, or sharpen a local passage.
- Keep example rewrites narrow. One sentence, one transition, one topic sentence, one possible merge, not a replacement draft.

## Do not drift

- Do not flatten the author's voice into generic "clean prose."
- Do not quietly rewrite paragraph after paragraph.
- Do not treat every style issue as a grammar lesson.
- If the real issue is structural, say so plainly instead of pretending style will solve it.
