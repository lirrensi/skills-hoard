# Distillation Guidance

Distillation is optional.
Do it only when the user wants a smaller, more operational output.

## Common distillation targets

- small procedural skill
- task guide or SOP
- troubleshooting flow
- quick-reference sheet
- briefing document
- curated reading or source pack

## Distillation rules

- read from the corpus, not from memory alone
- define the target audience and use case first
- name what is being left out
- preserve pointers back to deeper material where possible
- keep the source folder intact; do not replace it with the compressed output

## Good candidates for compression

- repeated decisions that already have enough evidence
- stable procedures
- high-frequency troubleshooting paths
- minimal starter knowledge for a narrow role

## Bad candidates for premature compression

- disputed areas
- weakly sourced claims
- rapidly changing material
- domains where the taxonomy is still unstable

Use `templates/distillation_brief.md` before producing the smaller artifact.
