# Knowledge Accumulator

This directory contains the active `knowledge-accumulator` skill plus its references and templates.

The goal is simple:

- accumulate knowledge in one durable folder
- keep it retrievable with taxonomy and source mapping
- iterate across many sessions
- optionally distill the result into a smaller procedure, guide, or skill later

## Active skill files

```text
knowledge-accumulator/
├── SKILL.md
├── README.md
├── references/
└── templates/
```

## Design direction

This skill is built around a few core ideas:

- corpus as source of truth
- taxonomy-guided accumulation
- multi-session growth
- link vs embed discipline
- lightweight quality and coverage checks
- optional downstream generation

It changes the center of gravity from "build a giant skill" to "maintain a living knowledge base."

Read `references/design-decisions.md` for the reasoning behind the structure.
