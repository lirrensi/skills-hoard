# Voice Reference Template

This file is optional and user-owned.

The preferred setup is to place `VOICE.md` in the **project root**. That root file should take priority over this bundled template.

Use this file to define how the essay should sound.

`EDITING.md` governs editorial craft.
`VOICE.md` governs register, tone, rhythm, audience feel, and stylistic guardrails.

---

## Suggested structure

```markdown
# Voice Reference

## Core register
- [casual / conversational / sharp / restrained / warm / blunt / funny / etc.]

## Audience level
- [smart broad readers / niche community / publication audience / etc.]

## Keep
- [things the writing should keep sounding like]

## Avoid
- [things the writing should not drift into]

## Sentence feel
- [short and direct / mixed rhythm / longer reflective lines / etc.]

## Vocabulary guardrails
- [plain language / some jargon / no academic phrasing / etc.]

## Good traits
- [specificity, directness, energy, humor, etc.]

## Bad traits
- [throat-clearing, smugness, fake depth, corporate tone, etc.]

## Example lines
- [2-5 example sentences that sound right]
```

---

## Default behavior if no project-root VOICE.md exists

- Infer voice from the user's actual material.
- Preserve the strongest existing register.
- Do not upscale toward academic or prestige prose by default.
- Default to intelligent broad-reader clarity.
- When the task involves substantial rewriting or repeated iterations, ask whether the user wants to create `VOICE.md` for consistency.

---

## Broad-reader voice default

If the user wants the essay to feel accessible, emotionally alive, and non-academic, aim for this:

- conversational, not classroom
- smart, not showy
- plainspoken, not simplified into baby talk
- emotionally clear, not melodramatic
- strong enough to provoke feeling, not padded into politeness

### Practical guardrails

- Prefer words a teenager would know.
- If a simpler word does the same job, use the simpler word.
- Write like a real person talking clearly, not like a panelist performing intelligence.
- Keep sentences easy to follow on first read.
- Let anger, urgency, wonder, or tenderness come through in the meaning, not through inflated wording.

### Drift to avoid

- academic jargon
- prestige-magazine stiffness
- corporate language
- therapeutic vagueness
- faux-profound conclusions

### Good default sentence feel

- mostly clear, medium-length sentences
- short sentences where force matters
- longer sentences only when the rhythm stays easy to follow

### Example voice target

- "Here is the thing nobody wants to say."
- "That sounds small until you have to live inside it."
- "I am not trying to make this prettier than it was."
- "The problem was simple. The consequences were not."
