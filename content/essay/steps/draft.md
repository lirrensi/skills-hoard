# Step: Draft

Before drafting:

1. Check the project root for `EDITING.md` and use it if present.
2. If root `EDITING.md` is missing, offer to create it from the bundled template/reference or temporarily fall back to the bundled `EDITING.md`.
3. Check the project root for `VOICE.md` and use it if present.
4. If root `VOICE.md` is missing, infer voice from the material for this pass and ask whether the user wants to create `VOICE.md` if the task involves substantial rewriting or ongoing work.

## Goal

Build a coherent full draft from rougher material while preserving the intended voice.

## Focus

Use the structure and craft rules from `EDITING.md` to turn notes, fragments, or a loose outline into continuous prose.

Prefer synthesis over replacement.

Build around a real story, not just a sequence of events. Default to concrete detail, broad-reader clarity, and a deliberate balance of scene, summary, and reflection.

## Output format

```markdown
# Draft

[Full draft]

---

## Draft Notes
- [major assumptions]
- [uncertain passages]
- [recommended next step]
```
