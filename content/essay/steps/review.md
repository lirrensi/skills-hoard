# Step: Review

Before reviewing:

1. Check the project root for `EDITING.md` and use it if present.
2. If root `EDITING.md` is missing, offer to create it from the bundled template/reference or temporarily fall back to the bundled `EDITING.md`.
3. Check the project root for `VOICE.md` and use it if present.
4. If root `VOICE.md` is missing, infer voice from the material for this pass and ask whether the user wants to create `VOICE.md` if the task involves substantial rewriting or ongoing work.

## Goal

Give a tough editorial diagnostic of the essay's argument, structure, pacing, voice stability, and finishability.

## Focus

Judge the essay using the craft standards from `EDITING.md`, especially:
- situation versus story
- spine / one big idea
- structure and sequencing
- tension and payoff
- scene / summary / reflection balance
- emotional truth versus overexplanation
- dead zones
- made versus earned claims
- broad-reader accessibility
- voice drift
- whether the piece is actually close to done

[ ] Needs structural rework
[ ] Needs fundamental rethink

## Finishability
- **Main blocker type:** [structure / argument / pacing / line-level / mixed]
- **Distance from publishable:** [far / moderate / close]
- **Voice risk:** [none / slight drift / major drift]
- **Best next move:** [finalize / revise / polish / rethink]

## Recommendation
[Clear next step]
