# Step: Finalize

Before doing anything substantial:

1. Check the project root for `EDITING.md` and use it if present.
2. If root `EDITING.md` is missing, offer to create it from the bundled template/reference or temporarily fall back to the bundled `EDITING.md`.
3. Check the project root for `VOICE.md` and use it if present.
4. If root `VOICE.md` is missing, infer voice from the material for this pass and ask whether the user wants to create `VOICE.md` if the task involves substantial rewriting or ongoing work.

## Goal

Take messy but substantial material and turn it into a structured, coherent essay that feels finished while preserving the intended voice.

## Workflow

1. Dump everything out first.
2. Distinguish the **situation** from the **story**.
3. Find the one big idea.
4. Group notes into clusters.
5. Put the clusters in order by emotional and argumentative logic, not just chronology.
6. Decide where the essay needs scene, summary, and reflection.
7. Flesh out each cluster into a paragraph or section with concrete detail and broad-reader clarity.
8. Write transitions between sections.
9. Write intro and conclusion last.
10. Do one light edit pass for accessibility, rhythm, and overexplanation.

## Idea support

If the piece is missing something important, suggest only grounded improvements such as:
- a sharper thesis
- a clearer emotional core
- a missing example
- a scene that should be expanded
- a place where summary should replace draggy narration
- a stronger framing angle
- a transition option
- an ending option
- a cut / merge / split recommendation

Label these as suggestions.
