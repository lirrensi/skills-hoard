# Step: Revise

Before revising:

1. Check the project root for `EDITING.md` and use it if present.
2. If root `EDITING.md` is missing, offer to create it from the bundled template/reference or temporarily fall back to the bundled `EDITING.md`.
3. Check the project root for `VOICE.md` and use it if present.
4. If root `VOICE.md` is missing, infer voice from the material for this pass and ask whether the user wants to create `VOICE.md` if the task involves substantial rewriting or ongoing work.

## Goal

Edit a specific section or passage without breaking the essay's voice or structure.

## Focus

Use `EDITING.md` to identify what kind of revision is needed:
- tighten
- expand
- sharpen
- restructure
- bridge
- tone-correct

When useful, explain whether the passage needs more specificity, more reflection, less explanation, or a cleaner balance of scene and summary.

Show the revised passage and briefly explain what changed.

## Output format

```markdown
**Edit type:** [type]

**Revised section:**
[edited passage]

**Why this works:**
[brief explanation]

**Voice preserved:**
[yes / how]
```
