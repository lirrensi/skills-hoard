# Recommendation patterns

Use this file to move quickly from essence to a short, grounded shortlist of delivery options.

Do not treat these as fixed mappings. They are starting points for discussion.

| Essence | Good formats to explore | Good modalities to explore | Watch for |
|---|---|---|---|
| `summary` | `briefing`, `article / document`, `FAQ page` | `markdown / plain text`, `rich document / PDF`, `HTML page` | Do not overproduce a simple core idea |
| `q-and-a-pairs` | `FAQ page`, `interview`, `interactive quiz` | `markdown / plain text`, `HTML page`, `chat-style UI` | Keep answers grounded; do not turn factual answers into theater unless wanted |
| `timeline` | `walkthrough`, `visual timeline`, `briefing` | `slides`, `HTML page`, `audio` | Preserve sequence, transitions, and causal turns |
| `concepts-and-definitions` | `tutorial / lesson`, `reference sheet`, `article / document` | `HTML page`, `markdown / plain text`, `diagram / canvas` | Do not lose precise definitions while simplifying |
| `claims-and-evidence` | `debate script`, `briefing`, `article / document` | `audio`, `rich document / PDF`, `HTML page` | Keep evidence attached to claims and signal uncertainty |
| `entities-and-relations` | `diagram explainer`, `reference sheet`, `walkthrough` | `diagram / canvas`, `HTML page`, `markdown / plain text` | Relationship clarity matters more than pretty labels |
| `steps-and-procedures` | `tutorial / lesson`, `walkthrough`, `reference sheet` | `HTML page`, `markdown / plain text`, `slides` | Preserve order, preconditions, and failure points |
| `comparison` | `briefing`, `reference sheet`, `interactive quiz` | `rich document / PDF`, `HTML page`, `markdown / plain text` | Keep criteria consistent across options |
| `data-and-metrics` | `dashboard`, `briefing`, `article / document` | `interactive app`, `HTML page`, `rich document / PDF` | Do not flatten trends into disconnected numbers |
| `narrative-arc` | `narrative / story`, `comic / storyboard`, `explainer video script` | `video`, `markdown / plain text`, `audio` | Keep stakes and turning points intact |
| `action-items` | `briefing`, `email / memo`, `reference sheet` | `markdown / plain text`, `message body`, `rich document / PDF` | Actionability beats flourish |
| `arguments-and-counterarguments` | `debate script`, `interview`, `article / document` | `audio`, `markdown / plain text`, `HTML page` | Do not let one side quietly dominate unless that is the point |
| `patterns-and-themes` | `article / document`, `briefing`, `narrative / story` | `rich document / PDF`, `markdown / plain text`, `slides` | Avoid vague theme language without examples |
| `gaps-and-unknowns` | `briefing`, `email / memo`, `FAQ page` | `message body`, `rich document / PDF`, `markdown / plain text` | Honesty and decision relevance matter more than polish |
| `cause-and-effect-chains` | `walkthrough`, `diagram explainer`, `tutorial / lesson` | `diagram / canvas`, `slides`, `HTML page` | Keep mechanisms explicit, not just outcomes |
| `rules-and-constraints` | `reference sheet`, `FAQ page`, `article / document` | `markdown / plain text`, `HTML page`, `printable one-pager` | Precision matters; avoid paraphrases that weaken rules |
| `examples-and-cases` | `case study`, `tutorial / lesson`, `narrative / story` | `rich document / PDF`, `HTML page`, `video` | Examples should illuminate the principle, not just entertain |
| `sentiment-and-opinion` | `interview`, `dialogue / podcast`, `social thread` | `audio`, `chat-style UI`, `message body` | Preserve speaker stance and intensity faithfully |
| `prerequisites-and-dependencies` | `walkthrough`, `reference sheet`, `tutorial / lesson` | `diagram / canvas`, `HTML page`, `markdown / plain text` | Keep gating logic and unlock order visible |
| `taxonomy` | `reference sheet`, `diagram explainer`, `FAQ page` | `diagram / canvas`, `HTML page`, `printable one-pager` | Categories should stay mutually clear and navigable |

## Heuristics

- Reach for `briefing` when the user wants speed, decision support, or stakeholder alignment.
- Reach for `walkthrough` when order, sequence, or guided pacing matters.
- Reach for `tutorial / lesson` when the user should learn by progression, not just read.
- Reach for `dialogue / podcast` or `interview` when voice, tension, or conversational access helps.
- Reach for `reference sheet` or `FAQ page` when lookup beats immersion.
- Reach for **HTML artifact** (M03) when the content benefits from interactivity, mixed media, or
  stateful exploration — dashboards, quizzes, simulations, filterable comparisons, interactive
  explainers. See `formats.md` for the full HTML artifact note.
