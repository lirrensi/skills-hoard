# YouTube Best Practices

## Platform Characteristics

- **Description limit**: 5,000 characters for videos
- **Best for**: Long-form video, tutorials, entertainment, search discovery
- **Audience**: Everyone (broadest platform)
- **Tone**: Engaging, personality-driven, structured

## Post Types

### Long-Form Video
Best for: Tutorials, deep dives, vlogs, reviews

**Structure:**
- Hook (first 10-15 seconds): Show the result/benefit
- Introduction: Who this is for, what you'll learn
- Body: Main content with chapters
- Conclusion: Summary + CTA (subscribe, like, comment)

**Description:**
- First 2-3 lines most important (visible in search)
- Include timestamps for key sections
- Add relevant links (timestamps link to video moments)
- Include keywords for searchability

### Shorts
Best for: Discovery, viral reach, younger audience

**Structure:**
- Hook (0-2 sec): Pattern interrupt
- Content (30-60 sec): Single value
- CTA (final sec): Follow, check full video

**Specs:**
- Up to 3 minutes
- 9:16 vertical format
- Similar to TikTok/Reels

## Best Practices

### Video Hook
The first 10 seconds determine whether people keep watching:
- Show the end result/benefit immediately
- Make a bold promise
- Create curiosity gap
- Don't waste time with long intros

### Chapter System
- Add timestamps in description
- Structure: "0:00 - Intro 1:30 - Topic 1 3:45 - Topic 2"
- Chapters help retention and SEO

### Description Optimization
- First 2-3 lines visible in search results
- Include primary keywords
- Add timestamps
- Link to relevant videos/playlists
- Include social links

### Title Optimization
- Include primary keyword
- Make it curiosity-driving
- Under 60 characters
- Avoid clickbait (algorithm penalty)

### Thumbnail Optimization
- High contrast
- Large readable text
- Face with expression (when possible)
- Consistent branding

### SEO Notes
- YouTube is owned by Google = search intent matters
- Keywords in title, description, tags help discovery
- Watch time and retention = primary ranking factor
- Engagement signals (likes, comments, shares) matter

### Engagement Tips
- Respond to comments (especially early ones)
- Ask questions in video for comment engagement
- End screens with clear CTA
- Community posts for non-video engagement
