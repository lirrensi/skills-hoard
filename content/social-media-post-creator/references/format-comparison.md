# Cross-Platform Format Comparison

## Quick Reference: Character Limits

| Platform | Hard Limit | Visible Before "See More" | Best Format |
|----------|-----------|---------------------------|-------------|
| Twitter/X | 280 (25K Premium) | Full | Single idea, thread |
| LinkedIn | 3,000 | ~2 lines | Short post, carousel |
| Instagram | 2,200 | ~125 chars | Visual + caption |
| Threads | 500 (+10K attachment) | Full | Conversation |
| Facebook | 63,206 | ~3-4 lines | Native content |
| TikTok | 2,200 desc | Title area | Video script |
| YouTube | 5,000 desc | First 2-3 lines | Long-form video |
| Pinterest | 500 desc | Varies | Image + keywords |

## Format Decision Guide

### By Content Type

**Single insight / hot take:**
- Twitter (single tweet)
- LinkedIn (short post with hook)
- Threads (short post)

**Step-by-step process:**
- LinkedIn (carousel)
- Instagram (carousel)
- TikTok (video)
- YouTube (tutorial video)
- Pinterest (Idea Pin)

**Story / experience:**
- LinkedIn (story post)
- Instagram (Reel)
- Twitter (thread)
- Facebook (personal post)

**Announcement:**
- Twitter (tweet + thread if needed)
- LinkedIn (professional post)
- Instagram (post + story)
- Facebook (native post)

**Educational content:**
- LinkedIn (carousel)
- Instagram (carousel/Reel)
- TikTok (educational short)
- YouTube (tutorial)
- Pinterest (how-to pin)

### By Audience

**Tech/Developer:**
- Twitter, LinkedIn, YouTube

**B2B/Professional:**
- LinkedIn, Twitter

**B2C/Consumer:**
- Instagram, TikTok, Pinterest

**Broad/General:**
- Facebook, YouTube

**Younger (16-34):**
- TikTok, Instagram, Threads

**Older (35+):**
- Facebook, LinkedIn

## Format Transformation Examples

### Article → Social

| Platform | Adaptation |
|----------|-----------|
| Twitter | Thread of key takeaways |
| LinkedIn | Hook + summary + link |
| Instagram | Carousel of main points |
| Facebook | Key insight + link |
| Pinterest | Visual + link |

### Presentation → Social

| Platform | Adaptation |
|----------|-----------|
| Twitter | Thread (1 point per slide) |
| LinkedIn | Carousel (slide = card) |
| Instagram | Carousel + Reel summary |
| TikTok | Short video demo |

### Podcast Episode → Social

| Platform | Adaptation |
|----------|-----------|
| Twitter | Thread of best quotes |
| LinkedIn | Quote graphic + insight |
| Instagram | Clip as Reel |
| TikTok | Short clip with caption |
| YouTube | Shorts from best moments |

## The "One Idea" Rule

Across all platforms, one principle holds:

> **One clear idea per post.**

If your essence has multiple points:
- Twitter: Split into thread (1 tweet per point)
- LinkedIn: Use carousel or series
- Instagram: Multiple posts or carousel
- Adapt, don't compress

## Adaptation vs. Cross-Posting

### ❌ Cross-Posting (Don't Do This)
Same content, same format, same platform:
> "Check out our new feature! [link]"
> (Posted identically to Twitter, LinkedIn, Instagram)

### ✅ Adaptation (Do This)
Same core message, platform-native format:
> Twitter: "Just launched [feature]. Here's the key benefit:"
> LinkedIn: Story of problem → solution → [feature]
> Instagram: Visual of feature in action + caption

## Validation Checklist

Before publishing any platform version:

- [ ] Hook works within visible limit
- [ ] One clear idea per post
- [ ] Platform conventions followed
- [ ] CTA is clear
- [ ] Length within limits
- [ ] Format matches platform best practices
- [ ] Content adapted, not copied
