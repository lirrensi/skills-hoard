# Pinterest Best Practices

## Platform Characteristics

- **Title limit**: 100 characters
- **Description limit**: 500 characters (800 in some contexts)
- **Best for**: Discovery, evergreen content, visual search
- **Audience**: Intent-driven (searching for ideas/solutions)
- **Tone**: Inspirational, visual-first

## Platform Type

Pinterest is fundamentally different from other social platforms:
- **Search/Intent-driven**: Users search for ideas, not scroll feeds
- **Evergreen**: Content has long shelf life (months/years)
- **Discovery**: Users find content via search, not follows

## Post Types

### Standard Pin
Best for: Blog posts, products, ideas

**Structure:**
- Title: Keyword-rich, benefit-driven
- Description: Search-optimized, include keywords
- Image: Vertical 2:3 aspect ratio

### Idea Pin
Best for: Step-by-step, multi-image content

**Structure:**
- Multiple slides/pages
- Can include video
- Interactive elements

## Best Practices

### Image Specs
- Aspect ratio: 2:3 (1000x1500 recommended)
- Vertical performs best
- High resolution
- Text overlay for context

### Title Optimization
- Include primary keyword
- Under 100 characters
- Benefit-driven: "How to [outcome]"
- Specific: "10 [things] for [topic]"

### Description Optimization
- Use first for searchability
- Include relevant keywords naturally
- 500 characters max
- Write for discovery, not reading

### SEO Notes
- Descriptions used for algorithm relevance
- Keywords matter more than other platforms
- Board organization helps discovery
- Rich Pins provide more metadata

### What Works
- Step-by-step guides (listicles)
- DIY and how-to content
- Recipes
- Fashion and beauty
- Home decor
- Infographics
- Evergreen content

### What Doesn't Work
- Outdated/seasonal content (unless specifically seasonal)
- Non-visual content (Pinterest is visual-first)
- Links to non-optimized pages

### Engagement Model
- Saves > likes
- Click-through to website
- Users save for later (intent to return)
- Comments less common

## Platform-Specific Notes

Pinterest is unique because:
1. Content is "saved" not "posted"
2. Discovery is search-based, not feed-based
3. Evergreen beats viral (search demand persists)
4. Images are the primary content, text is secondary
5. Users have intent (searching for solutions)

This changes how you adapt content:
- Optimize for search terms
- Write descriptions for discovery
- Design for save/return behavior
- Think evergreen, not time-sensitive
