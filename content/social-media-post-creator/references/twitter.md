# Twitter/X Best Practices

## Platform Characteristics

- **Character limit**: 280 characters standard, 25,000 with Premium
- **Best for**: Real-time conversation, hot takes, threads, quick insights
- **Audience**: Tech-savvy, news-oriented, niche communities
- **Tone**: Direct, opinionated, concise

## Post Types

### Single Tweet
Best for: Quick insights, reactions, questions, one-liners

**Structure:**
1. Hook (first line must stand alone)
2. Core message
3. Optional: CTA or engagement prompt

**Length:** Under 280 chars (ideally 100-200 for engagement)

### Thread
Best for: Tutorials, stories, detailed breakdowns, multi-point insights

**Structure:**
1. Tweet 1: Hook + promise (must work without thread context)
2. Tweet 2-7: One point per tweet, each readable alone
3. Final tweet: Summary + CTA (follow, retweet, link)

**Tips:**
- Number tweets (1/N, 2/N) for clarity
- Each tweet should work if someone only reads one
- End with clear CTA

### Long-Form Article
Best for: In-depth analysis, evergreen content (Premium only)

**Structure:**
- Write as formal article with headings
- Use native formatting
- Include media

## Best Practices

### Hook Formulas That Work
- "TIL: [insight]"
- "[Contrarian take]"
- "[Specific number] [things] about [topic]:"
- "The [adjective] truth about [topic]:"
- Question that invites reply

### What Works
- Strong opinions and hot takes
- Specific numbers and data
- Threads that teach something
- Engagement with replies
- Quote tweets with added insight

### What Doesn't Work
- Threads without strong hook
- Generic motivation
- Links in main body (count toward limit)
- Hashtag spam (1-2 max)
- Ignoring replies

### Engagement Tips
- Reply to engagees quickly (first 30 min matters)
- Quote tweet with insight beats plain RT
- Use polls for engagement
- Retweet with comment adds value

## Visible Limit Note

The full tweet is visible in most contexts. For threads, the first tweet's first line is critical — it appears in preview when someone quotes your thread.
