# Distill Mode

Use this mode when the source material is a large corpus, a repo, a manual collection, or a
long idea dump that needs to become a field-manual-style skill.

## Distillation Stance

- Distillation is optional, but it is the right move when the source is too large to keep in
  one skill body.
- The source corpus stays canonical.
- The skill is a compressed downstream product.
- Keep the folder intact; do not replace the source corpus with the compressed output.

## Common Distillation Targets

- a small procedural skill
- a task guide or SOP
- a troubleshooting flow
- a quick-reference sheet
- a briefing document
- a curated source pack

## Workflow

1. Read the corpus, not memory alone.
2. Define the audience and use case first.
3. Pull out the transferable core: rules, checks, examples, and decision points.
4. Name what is being left out.
5. Preserve pointers back to deeper material where possible.
6. Reshape the core into a field manual: rule, example, checklist, recovery path.
7. Validate that the compressed output still lets an agent act correctly.

## What To Keep

- stable procedures
- repeated decisions with enough evidence
- high-frequency troubleshooting paths
- narrow starter knowledge for a role
- anti-patterns and failure modes

## What To Avoid Compressing Too Early

- disputed areas
- weakly sourced claims
- rapidly changing material
- unstable taxonomies
- anything that still needs corpus growth before judgment is safe

## Source-Specific Tips

- Blog posts: extract the small actionable core and expand with your own concrete examples.
- Repos: focus on architectural patterns, utilities worth copying, and deliberate absences.
- Documentation: restructure around when to use something, not just what it is.
- Papers: extract the insight or theorem, then translate it into practical rules.
- Video transcripts: scan for the few prescriptive moments and ignore the filler.

## Distillation Patterns

- Inversion: rule -> example -> anti-pattern.
- Translation: move abstract ideas into the user's ecosystem.
- Compression: keep only what changes decisions or actions.
- Cross-reference: point to companion skills instead of repeating deep material.

## Validation Check

- Can the skill be used without the original corpus open?
- Did we preserve the manual rules, examples, and checklist structure?
- Are the omitted parts named or linked?
- Did the output stay lean without becoming vague?
