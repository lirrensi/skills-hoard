# Create Mode

Use this mode when building a new skill or turning a scoped source packet into a first draft.

If the input is a large corpus, manual, repo, or idea dump, use `distill.md` first to
extract the transferable core before drafting the skill.

## Inputs To Collect

- target outcome
- audience or user
- source material
- local comparison skills
- constraints on scope, style, or tools
- validation target

## Workflow

1. Inventory the source material.
2. Separate raw notes, examples, and requirements.
3. Distill the transferable core if the source packet is broad.
4. Decide whether a new skill is actually needed.
5. Draft a narrow `description` that triggers the right tasks.
6. Keep `SKILL.md` lean and move repeated detail into references.
7. Add scripts only when a repeated step needs deterministic behavior.
8. Validate against realistic prompts and near-miss prompts.

## Quality Gates

- The skill should clearly say what it does and what it does not do.
- The core flow should be readable in one pass.
- Long guidance should live in references, not in `SKILL.md`.
- The result should depend on source material, not invented filler.
- The compression should preserve the useful manual rules, examples, and checks.
