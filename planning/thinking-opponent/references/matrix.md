# 🧠 Oppositional Thinker's Framework
### A Clustered Matrix with Decision Triage

---

## HOW TO USE THIS

1. **Run the Triage Questions** (Section 1) to identify the primary pressure lane
2. **Build a convergent loadout** (Section 1.5) so several tools hit the same core idea
3. **Go to the primary cluster** (Section 2) and choose the anchor tool or tools
4. **Add cross-lens tools** from Evidence, Causal, Language, and Risk so the cracks compound
5. **Use the rest as reference** — do not turn this into a kitchen-sink framework dump

---

## SECTION 1 — TRIAGE DECISION TREE

Ask these in order. Stop at the first match.

```
Q1: Is the problem about EVIDENCE — what's actually true?
    → YES → Go to Cluster A (Evidence Hygiene) or B (Causal Traps)

Q2: Is the problem about LANGUAGE or FRAMING?
    → YES → Go to Cluster C (Language & Frame)

Q3: Are OTHER AGENTS reacting to you (people, institutions, markets)?
    → YES → Go to Cluster D (Social & Game Theory)

Q4: Could any outcome here be CATASTROPHIC or irreversible?
    → YES → Go to Cluster E (Risk & Ruin)

Q5: Is the problem about YOUR OWN BELIEFS or how you're updating them?
    → YES → Go to Cluster F (Epistemics & Updating)

Q6: Is this about GENERATING or STRUCTURING ideas?
    → YES → Go to Cluster G (Creative Pressure)

Q7: Is this about ANALYZING a system or decision over time?
    → YES → Go to Cluster H (Systems & Time)
```

---

## SECTION 1.5 — CONVERGENT ATTACK BUILD

Once you know the primary cluster, do not stay trapped in one lane.

For a single idea, the default oppositional package is:

- **1 Evidence tool** — is this actually true?
- **1 Causal tool** — what actual mechanism makes it happen?
- **1 Language tool** — is framing or ambiguity hiding weakness?
- **1 Risk tool** — how does it fail, backfire, or become unrecoverable?

Add an optional fifth tool only when one of these is clearly load-bearing:

- **Social & Game Theory** — incentives, politics, adaptation, audience reaction
- **Epistemics & Updating** — overconfidence, disputed cruxes, asymmetric skepticism
- **Systems & Time** — scale, second-order effects, feedback loops, long-run rot

### Core rule

All selected tools should attack the **same core claim**.
Do not spend one tool on one side issue and another tool on a different side issue unless you have first split the idea into separate claims.

### Default attack sequence

1. **Language first** — strip perfume words and define the claim cleanly
2. **Evidence second** — ask whether the claim has earned belief
3. **Causal third** — ask whether the mechanism actually exists
4. **Risk fourth** — ask how the real-world version fails
5. **Optional fifth** — test adaptation, scale, politics, or belief-updating weakness

### Convergence check

After the passes, ask:

- Which weakness showed up in two or more lenses?
- Which assumption looked harmless until multiple tools hit it?
- Which contradiction survives even after the idea is steelmanned?

Those are your real kill shots.

### Fast build examples

| Primary problem | Convergent loadout |
|---|---|
| Truth claim sounds inflated | Semantic audit -> Falsification thinking -> Mechanism thinking -> Pre-mortem |
| Causal story sounds fake | Semantic audit -> Mechanism thinking -> Confounding check -> Tail-risk / ruin thinking |
| Slick framing is doing the work | Semantic audit -> Motte-and-bailey detection -> Falsification thinking -> Pre-mortem |
| High-stakes plan with downside | Semantic audit -> Base-rate thinking -> Mechanism thinking -> Tail-risk / ruin thinking -> Goodhart thinking |
| Public or political argument | Semantic audit -> Falsification thinking -> Mechanism thinking -> Pre-mortem -> Motive archaeology |

## SECTION 2 — THE 8 CLUSTERS

---

### CLUSTER A — Evidence Hygiene
> *Don't lie to yourself about what the data says*

**Use when:** You have data, studies, or observations and need to trust them correctly.

| Tool | One-liner |
|------|-----------|
| **Falsification thinking** | What would kill this idea? Go look for that. |
| **Null-hypothesis thinking** | Assume no effect. Demand strong reasons to believe otherwise. |
| **Base-rate thinking** | What usually happens in cases like this? Statistical cold shower. |
| **Survivorship-bias check** | What failures aren't in your dataset? |
| **Selection-effect check** | Are you seeing this because it's true, or because of how you're looking? |
| **Confounding check** | What third variable could be causing both things you're correlating? |
| **Sensitivity analysis** | Which assumption, if wrong, makes your conclusion collapse? |

**Combat loadout (pick 1):** Falsification → Survivorship → Base-rate

---

### CLUSTER B — Causal Traps
> *Reality lies about cause and effect constantly*

**Use when:** You're trying to establish what caused what, or what will cause what.

| Tool | One-liner |
|------|-----------|
| **Mechanism thinking** | By what actual machinery would A produce B? |
| **Confounding check** | Hidden third variable pulling both strings? |
| **Collider-bias suspicion** | Two things look related only because you selected on a shared outcome? |
| **Omitted variable thinking** | What important factor is missing from the model entirely? |
| **Path dependence** | Is this outcome optimal, or just historically locked in? |
| **Counterfactual thinking** | What would be true if this assumption were false? |

**Combat loadout (pick 1):** Mechanism → Counterfactual → Confounding

---

### CLUSTER C — Language & Frame
> *Words are doing crime. Find the crime.*

**Use when:** The argument feels slippery, terms are fuzzy, or you suspect framing is doing the work.

| Tool | One-liner |
|------|-----------|
| **Semantic audit** | What does this word actually mean? Define it. Watch arguments dissolve. |
| **Category questioning** | Why is this thing in this category at all? |
| **Vocabulary imperialism** | Which field's terminology has colonized your thinking? |
| **Motte-and-bailey detection** | Bold claim defended by retreating to a weaker one, then sneaking back. |
| **Load-bearing ambiguity** | A vague phrase doing structural work — define it and the argument may collapse. |
| **Frame capture** | If the other side defined the terms, you may have already lost. |
| **Reframing** | Same problem, different door. "How do I stop losing" ≠ "How do I win." |
| **Rhetorical asymmetry detection** | Where are charged words replacing actual argument? |

**Combat loadout (pick 1):** Semantic audit → Motte detection → Frame capture

---

### CLUSTER D — Social & Game Theory
> *Other agents are not static. They adapt.*

**Use when:** Your problem involves people, institutions, incentives, or politics.

| Tool | One-liner |
|------|-----------|
| **Motive archaeology** | Why does this person *need* this to be true? |
| **Principal-agent thinking** | Decider ≠ consequences-bearer. Different incentives. |
| **Game-theoretic reasoning** | What happens when everyone responds strategically to your move? |
| **Equilibrium thinking** | What stable pattern emerges after everyone adapts? |
| **Coordination thinking** | Is this an optimization problem or an alignment problem? |
| **Preference falsification** | People say X publicly, believe Y privately. Which is driving behavior? |
| **Common-knowledge thinking** | Not just "everyone knows X" but "everyone knows everyone knows X." |
| **Goodhart thinking** | Once a measure becomes a target, it stops measuring the real thing. |
| **Audience partitioning** | Who is this argument actually for? |
| **Scapegoat detection** | Is this explanation useful because it names a villain, not because it's accurate? |

**Combat loadout (pick 1):** Motive archaeology → Principal-agent → Goodhart

---

### CLUSTER E — Risk & Ruin
> *Low probability ≠ ignorable. Some outcomes are unrecoverable.*

**Use when:** Stakes are high, volatility is possible, or a bad outcome is irreversible.

| Tool | One-liner |
|------|-----------|
| **Tail-risk / ruin thinking** | Even if unlikely — is there an unrecoverable outcome here? |
| **Fragility thinking** | What looks fine until volatility hits it? |
| **Reversibility thinking** | One-way door or two-way door? |
| **Robustness thinking** | What works across many assumptions, not just your favorite? |
| **Antifragility thinking** | Does this merely survive stress, or improve because of it? |
| **Pre-mortem** | Imagine catastrophic failure. Work backwards. What caused it? |
| **Option-value thinking** | Which choice keeps doors open? |

**Combat loadout (pick 1):** Tail-risk → Reversibility → Pre-mortem

---

### CLUSTER F — Epistemics & Updating
> *How you update beliefs. Where your certainty is leaking.*

**Use when:** You're forming or revising beliefs, or you suspect you're overconfident/underconfident.

| Tool | One-liner |
|------|-----------|
| **Bayesian updating** | How much should this evidence actually move me? |
| **Calibration thinking** | When you say 80% confident — are you right 80% of the time? |
| **Asymmetric skepticism audit** | Are you harder on ideas you dislike than ideas you like? |
| **Crux identification** | What specific belief, if resolved, would change the conclusion? |
| **Double-crux thinking** | Where would BOTH sides update if proven wrong? |
| **Obviousness suspicion** | If everyone agrees, that's a red flag, not reassurance. |
| **Consensus genealogy** | Where did "everyone knows X" actually come from? Go check. |
| **Underdetermination thinking** | Your evidence supports your conclusion AND several contradictory ones. You just stopped looking. |
| **Abductive reasoning** | Which story best explains the pattern with the least strain? |
| **Outside-view / inside-view split** | What does this specific case suggest vs. what does the historical class predict? |

**Combat loadout (pick 1):** Asymmetric skepticism → Crux ID → Consensus genealogy

---

### CLUSTER G — Creative Pressure
> *Force new ideas out. Break the obvious solution.*

**Use when:** You're stuck, you need ideas, or the obvious answer feels wrong.

| Tool | One-liner |
|------|-----------|
| **Inversion thinking** | How would I guarantee failure? Now flip it. |
| **Constraint thinking** | What if I could only use X? Artificial limits force creativity. |
| **Constraint removal** | What would I do with infinite resources? Find what you actually want. |
| **Analogical mapping** | Find a structurally identical problem in another domain. Steal its solution. |
| **Transfer** | Solved problem from domain A → unsolved problem in domain B. |
| **Representation thinking** | Change how the problem is encoded. The puzzle may melt. |
| **Generative-first thinking** | Produce many options before evaluating any. Judgment is a creativity tax. |
| **Naive question weapon** | What would a smart 10-year-old ask? Adults call this being unsophisticated. It's actually powerful. |
| **Exception hunting** | Where does this theory fail? Exceptions are trapdoors into the real model. |
| **Overton window mapping** | What ideas are unsayable here, and why? That's where the interesting stuff lives. |

**Combat loadout (pick 1):** Inversion → Naive question → Constraint removal

---

### CLUSTER H — Systems & Time
> *Stop treating problems as static. They're loops and timelines.*

**Use when:** You're dealing with complex systems, long time horizons, or feedback dynamics.

| Tool | One-liner |
|------|-----------|
| **Second-order thinking** | What happens after what happens? The real game starts at consequence #2. |
| **Systems thinking** | Treat it as a loop of interactions, incentives, and feedback — not a thing. |
| **Feedback-loop thinking** | What reinforces itself here? What dampens? Some problems are spirals. |
| **Time-scale thinking** | What looks smart in a week may be stupid in a year. |
| **Bottleneck thinking** | One thing is broken loudest. Find the constraint governing the whole system. |
| **Local vs. global optimum** | Did you find the best move, or just the best move nearby? |
| **Marginal thinking** | Not "is this good" — but "what happens if I add one more unit?" |
| **Decomposition** | Cut the fog into subproblems until one piece becomes embarrassingly solvable. |
| **Resolution collapse** | Zoom way in OR way out. "Crime is rising" changes meaning completely at neighborhood vs. continental scale. |
| **Error-correction thinking** | How quickly does this system notice mistakes and repair them? |
| **Anti-legibility suspicion** | What can't be measured is usually what matters most. Institutions ignore it. |

**Combat loadout (pick 1):** Second-order → Bottleneck → Systems thinking

## SECTION 3 — QUICK TRIAGE CHEAT SHEET

| Situation | Cluster |
|-----------|---------|
| "Is this actually true?" | A — Evidence Hygiene |
| "What caused this?" | B — Causal Traps |
| "Something feels slippery about the argument" | C — Language & Frame |
| "People / politics / incentives involved" | D — Social & Game Theory |
| "High stakes, could go badly wrong" | E — Risk & Ruin |
| "Not sure what to believe / how confident to be" | F — Epistemics |
| "Stuck, need new ideas, obvious answer feels wrong" | G — Creative Pressure |
| "Complex system, long time horizon, feedback loops" | H — Systems & Time |

## SECTION 4 — THE MASTER COMBAT LOADOUT
*If you could only keep 12 tools for field use:*

1. **Inversion** (G) — destroy it to understand it
2. **Falsification** (A) — what would kill this?
3. **Second-order thinking** (H) — what happens after what happens?
4. **Motive archaeology** (D) — why does someone need this to be true?
5. **Pre-mortem** (E) — imagine failure, work backwards
6. **Semantic audit** (C) — define the key terms
7. **Base-rate thinking** (A) — what usually happens?
8. **Asymmetric skepticism** (F) — are you applying equal scrutiny?
9. **Crux identification** (F) — what belief, if resolved, changes everything?
10. **Bottleneck thinking** (H) — what's actually governing the system?
11. **Tail-risk thinking** (E) — is there an unrecoverable outcome?
12. **Motte-and-bailey detection** (C) — where's the retreat position?
