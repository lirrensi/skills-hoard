# Evaluation Lanes

Choose the lane that matches the structure of the decision. Use rigor to clarify the choice, not to fake certainty.

## Quick Lane

Use when the decision is reversible and low-stakes.

Process:

1. check must-haves
2. compare the top 2-3 options briefly
3. run one debiasing prompt
4. choose and move

Good output:

- threshold judgment
- short rationale
- immediate next step

## Trade-Off Lane

Use when multiple alternatives must be compared across conflicting criteria.

Process:

1. eliminate options that fail must-haves
2. define 4-8 criteria
3. weight the criteria proportionally
4. score consistently or compare qualitatively if numbers are weak
5. test whether small weight or score changes flip the answer

Good output:

- strongest option or close call
- key trade-offs that drove the result
- sensitivity note

## Sequence Lane

Use when timing, waiting, piloting, or stage-gates matter.

Process:

1. map `act now`, `pilot`, and `wait` branches
2. note what each branch teaches
3. compare the value of learning against the cost of delay
4. choose the smallest commitment that still advances the goal

Good output:

- now vs wait vs pilot recommendation
- what the pilot or delay is meant to learn
- follow-up decision date

## Value Lane

Use when costs and benefits can be estimated credibly enough to matter.

Process:

1. define the baseline
2. list major upside, downside, and cost categories
3. separate monetizable from non-monetizable effects
4. estimate ranges, not fake-precise points, when uncertainty is high
5. identify the assumptions that would flip the result

Good output:

- expected-value or cost-benefit comparison
- assumptions and ranges
- note on what the numbers do not capture

## Uncertainty Lane

Use when future conditions dominate the choice.

Process:

1. define the decision horizon
2. identify 2-4 plausible future states
3. stress-test each option across those states
4. identify no-regrets moves, hedges, and big bets
5. define signposts to monitor

Good output:

- robust option or staged portfolio of moves
- scenario-sensitive risks
- signposts and trigger conditions

## Dynamic Lane

Use when the situation keeps moving and action itself creates information.

Process:

1. observe the few signals that matter most
2. orient by updating assumptions
3. decide on the next smallest useful move
4. act and collect feedback
5. repeat on a clear cadence

Good output:

- short action loop
- monitored signals
- explicit cadence for update

## Lane Selection Notes

- If the user wants a final answer fast and the decision is light, stay in quick.
- If the user keeps saying `it depends`, that often means sequence or uncertainty lane.
- If the team is arguing more about weights than about facts, the blocker may be group dynamics rather than analysis.
