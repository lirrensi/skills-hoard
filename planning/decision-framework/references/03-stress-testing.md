# Stress Testing

Do not let the first attractive answer become the final answer without challenge.

## Minimum Challenge Set

For modest decisions, use at least one:

- consider-the-opposite
- 10/10/10
- quick pre-mortem

For significant decisions, use at least two:

- outside view
- pre-mortem
- sensitivity analysis
- regret minimization

For high-stakes decisions, use three or more and capture the results explicitly.

## Methods

### Outside View

Ask:

- What happened in similar cases?
- What base rate or reference class should inform this?
- Are we treating our case as uniquely special without evidence?

Use when optimism, novelty, or overconfidence may be distorting judgment.

### Consider-The-Opposite

Ask:

- If the current favorite is wrong, what is the strongest case against it?
- What evidence would support the runner-up instead?

Use when the user already seems attached to one option.

### Pre-Mortem

Assume the decision failed 6-12 months from now.

Ask:

- Why did it fail?
- Which causes were within our control?
- What early warning signs would have shown up?

Convert findings into mitigations, signposts, or scope reductions.

### 10/10/10

Ask how the user will feel about the decision in:

- 10 minutes
- 10 months
- 10 years

Use when short-term emotion may be overpowering medium- or long-term value.

### Regret Minimization

Ask:

- Which option is more regrettable to take?
- Which option is more regrettable not to take?

Use when the choice is identity-laden, emotionally loaded, or tied to missed-opportunity fear.

### Sensitivity Analysis

Ask:

- If one major weight changes, does the answer flip?
- If one key assumption fails, does the answer flip?
- If the likely downside is 2x worse, does the answer still hold?

Use whenever a structured comparison produces a narrow winner.

## Output Pattern

Always report:

- which challenge methods were used
- what changed, if anything
- the biggest remaining risk
- what signal would tell us we were wrong

## Anti-Patterns

- using stress tests as theater after the decision is already fixed
- generating risks without changing the plan
- treating every low-stakes choice like a disaster scenario exercise
